# Postman – Simple Execution Steps for FSAD Lab Exam

Purpose: Postman is used to test the REST APIs of our Node.js Book Cart application.

## Step 1: Start the server

Open VS Code terminal and execute:

```
node server.js
```

Output:

```
Server is running on http://localhost:3000
```

Keep the server running.

## Step 2: Open Postman

1. Open Postman.
2. Click New → HTTP Request.
3. Select the required HTTP method.
4. Enter the URL.
5. Click Send to execute the request.

## Step 3: Perform CRUD operations

### 1. GET – Display all books

- Method: `GET`
- URL:

```
http://localhost:3000/books
```

- Click Send.
- Displays all books.

### 2. GET – Display a particular book

- Method: `GET`
- URL:

```
http://localhost:3000/books/1
```

- Click Send.
- Displays book with ID 1.

### 3. POST – Add a new book

- Method: `POST`
- URL:

```
http://localhost:3000/books
```

- Select Body → raw → JSON.
- Enter:

```
{
  "title": "Harry Potter",
  "author": "J.K. Rowling",
  "price": 20,
  "quantity": 8
}
```

- Click Send.
- A new book will be added.

### 4. PUT – Update a book

- Method: `PUT`
- URL:

```
http://localhost:3000/books/1
```

- Select Body → raw → JSON.
- Enter:

```
{
  "title": "Updated Book",
  "author": "John",
  "price": 50,
  "quantity": 15
}
```

- Click Send.
- Book details will be updated.

### 5. PATCH – Update selected details

- Method: `PATCH`
- URL:

```
http://localhost:3000/books/1
```

- Select Body → raw → JSON.
- Enter:

```
{
  "price": 100
}
```

- Click Send.
- Only the price will be updated.

### 6. DELETE – Delete a book

- Method: `DELETE`
- URL:

```
http://localhost:3000/books/1
```

- Click Send.
- The book will be deleted.

## Step 4: Remember this table for the exam

| Method | Operation      | Purpose                 |
| ------ | -------------- | ----------------------- |
| GET    | Read           | Display books           |
| POST   | Create         | Add a book              |
| PUT    | Update         | Update complete details |
| PATCH  | Partial Update | Update selected details |
| DELETE | Delete         | Remove a book           |

## Step 5: Important Postman points

1. Always start the Node.js server before opening API requests.
2. Use `localhost:3000` as the base URL.
3. For POST, PUT and PATCH, select Body → raw → JSON.
4. Click Send to execute the request.
5. Check the response in the lower section of Postman.
6. Do not stop the VS Code server while testing.
